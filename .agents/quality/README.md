# Quality Agents

This folder is reserved for code-quality guard agents for this repository.

## Intended Agent Types

- `i18n-guard`
- `comment-guard`
- `naming-guard`
- `template-guard`
- `cleanup-guard`

## Scope Rule

All quality agents must review only new or modified code.

They must not report legacy violations outside the current diff unless a dedicated legacy audit is requested.
