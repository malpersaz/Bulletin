Bu dosyanın görevi ve framework içindeki anlamı:

  Görevi:

  base.twig dosyası, bu PHP frameworkünün ana şablon (master template) 
  dosyasıdır. Tüm sayfaların temel HTML yapısını sağlayan merkezi bir layout
   dosyasıdır.

  Framework içindeki anlamı:

  1. Twig Template Engine Entegrasyonu

  - Twig şablon motorunu kullanan özel bir PHP frameworküdür
  - TwigLibs.class.php:92-96 dosyasında tanımlanan özel Twig fonksiyonları
  kullanır:
    - cssoptimize() - CSS dosyalarını birleştirir ve optimize eder
    - jsoptimize() - JavaScript dosyalarını birleştirir ve optimize eder
    - run() - Modül metotlarını çalıştırır

  2. Modüler Sistem

  - {{ run({"mod": "index", "method": "_menu"}) }} - Menu modülünü
  çalıştırır
  - Modül tabanlı mimari kullanır (mod/ klasörü altında modüller)

  3. Optimizasyon Özellikleri

  - CSS ve JavaScript dosyalarını otomatik birleştirir
  - Cache sistemi kullanır (cache/css/ ve cache/js/)
  - Versiyonlama sistemi vardır (?v= parametresi)

  4. Temel Yapısal Özellikleri

  - Responsive tasarım desteği
  - SEO için meta tag'ler (title, description, keywords)
  - Çoklu tema desteği (tema.php dosyasında default ve new temaları)
  - Dinamik içerik blokları ({% block %})

  5. Kullanıcı Yönetimi ve ACL

  - Yetki kontrol sistemi (permissions filtresi)
  - Grup bazlı erişim kontrolü
  - Session yönetimi

  Bu framework, özel bir PHP CMS/MVC framework'üdür ve base.twig dosyası tüm
   sistemin view katmanının temelini oluşturur.


Template Geliştirme Rehberi

  base.twig Dosyasını Verimli Kullanma Kılavuzu

  1. Template Sisteminin Temel Yapısı

  Bu framework'te template sistemi şu şekilde çalışır:

  - Ana Template: base.twig - Tüm sayfaların iskeleti
  - Child Template'ler: base.twig'i extend eden özel sayfa şablonları
  - Partial'ler: Tekrar kullanılabilir bileşenler (partials/ klasöründe)
  - Modül Template'leri: Her modülün kendi template'leri

  2. base.twig Doğru Kullanımı

  Block Sistemi:

  {% extends "layouts/base.twig" %}

  {% block title %}
      <title>Sayfa Başlığınız - {{ site.title }}</title>
  {% endblock %}

  {% block content %}
      <!-- Sayfa içeriği buraya gelir -->
  {% endblock %}

  {% block css_custom %}
      <link rel="stylesheet" href="custom.css">
  {% endblock %}

  {% block js_custom %}
      <script>
          // Sayfa özel JavaScript kodları
      </script>
  {% endblock %}

  3. CSS/JS Optimizasyon Sistemi

  Framework, CSS ve JS dosyalarını otomatik optimize eder:

  CSS Ekleme:

  {% block css_custom %}
      <!-- Sisteme CSS dosyası ekle -->
      {{ css({"url": "templates/default/static/css/custom.css"}) |raw }}
  {% endblock %}

  JavaScript Ekleme:

  {% block js_custom %}
      <!-- Sisteme JS dosyası ekle -->
      {{ js({"url": "templates/default/static/js/custom.js"}) |raw }}
  {% endblock %}

  Optimizasyon Özellikleri:

  - Otomatik birleştirme (concatenation)
  - Minification (sıkıştırma)
  - Cache sistemi
  - Versiyonlama
  - Gzip desteği

  4. Modüllerle Entegrasyon

  Modül Metot Çalıştırma:

  <!-- Menü sistemini çalıştır -->
  {{ run({"mod": "index", "method": "_menu"}) }}

  {% set menu = ctx_get('menu') %}

  Context Veri Yönetimi:

  <!-- Context'e veri ekleme -->
  {% do ctx_set('page_title', 'Hakkımızda') %}

  <!-- Context'ten veri çekme -->
  {% set page_title = ctx_get('page_title') %}

  5. Tema Geliştirme İpuçları

  Özel Bloklar Oluşturma:

  base.twig'e yeni bloklar ekleyebilirsiniz:

  <!-- base.twig'de -->
  {% block head %}
      {{ parent() }}
      {% block extra_meta %}{% endblock %}
  {% endblock %}

  <!-- Child template'de -->
  {% block extra_meta %}
      <meta property="og:title" content="Sayfa Başlığı">
  {% endblock %}

  Partial Kullanımı:

  <!-- Tekrar kullanılabilir bileşenler -->
  {% include 'partials/slider.twig' %}
  {% include 'partials/menu.twig' %}
  {% include 'partials/footer.twig' %}

  6. LESS/SCSS ile Tema Geliştirme

  Framework LESS dosyalarını destekler:

  // templates/default/static/less/custom.less
  @primary-color: #007bff;
  @secondary-color: #6c757d;

  .custom-button {
      background-color: @primary-color;
      border-radius: 5px;
  }

  7. Mobil Uyumlu Tasarım

  Bootstrap 5.3 tabanlı responsive tasarım:

  <!-- Responsive grid sistemi -->
  <div class="container">
      <div class="row">
          <div class="col-md-9 col-lg-8">
              Ana içerik
          </div>
          <div class="col-md-3 col-lg-4">
              Sidebar
          </div>
      </div>
  </div>

  8. Cache Yönetimi

  Template cache'i temizleme:
  # Cache klasörünü boşalt
  php clear_cache.php

  9. En İyi Pratikler

  Yapılması Gerekenler:

  - Her sayfa için base.twig'i extend edin
  - Block sistemi kullanarak kod tekrarını önleyin
  - CSS/JS optimizasyon sistemini kullanın
  - Responsive tasarım ilkelerine uyum sağlayın
  - LESS/SCSS değişkenleri kullanın

  Kaçınılması Gerekenler:

  - base.twig dosyasını doğrudan değiştirmek
  - Hardcoded URL'ler kullanmak
  - Inline CSS/JS yazmak (optimize sistemini kullanın)
  - Bootstrap grid yapısını bozmak

  10. Yeni Tema Oluşturma

  1. Temayı Kopyalayın:
  cp -r templates/default templates/yeni_tema
  2. Tema Ayarlarını Güncelleyin:
  // tema.php dosyasına ekleyin
  $valid_templates = array('default', 'new', 'yeni_tema');
  3. Özelleştirmeleri Yapın:
    - CSS dosyalarını düzenleyin
    - Template'leri ihtiyaca göre güncelleyin
    - Asset'leri özelleştirin
